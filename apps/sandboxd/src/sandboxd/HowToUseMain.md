how to use it

пишешь короче из корня проекта \
```docker compose -f docker-compose.sandboxd.yml up -d --build``` \
подключаешься к контейнеру  \
```docker attach <container_id> #(айдишник можно через docker ps или docker desktop узнать)``` 

И короче эта хуйня запускает SandboxShell в который можно слать комманды. \
После аттача должна в консоли появится \
```sandboxd> ``` \
туда вводишь комманды песочнице 

## Команды

| Команда | Что делает |
|---|---|
| `up` | Поднять `target` и `agent` в общей сети (создаёт сеть, если её ещё нет). Ничего не делает, если уже поднято — сначала `down`. |
| `down` | Погасить оба контейнера и удалить сеть. |
| `restart <alias>` | Пересоздать **один** узел (`target` или `agent`), не трогая сеть и соседний контейнер. Без явного манифеста — берёт тот, с которым узел поднимался в `up`. |
| `exec <alias> <команда...>` | Выполнить произвольную shell-команду **внутри** указанного контейнера (2-го уровня) и напечатать вывод. |
| `logs <alias> [tail]` | Показать последние N строк логов контейнера (по умолчанию 100). |
| `status` | Показать `running`/`stopped`/`not spawned` для обоих алиасов. |
| `exit` / `quit` / Ctrl-D | Погасить всё (если поднято) и выйти из shell. |
| `help` / `?` | Встроенная команда `cmd.Cmd` — печатает список всех `do_*`-методов с их докстрингами. |
| `help <команда>` | Докстринг конкретной команды. |

alias соотв. фиксированы – target и agent.
